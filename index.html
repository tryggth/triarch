1. What is Non-Transitivity?

In standard arithmetic, relations like "greater than" are transitive: if $A > B$ and $B > C$, then $A > C$. However, in probability spaces over discrete random variables, pairwise superiority is not guaranteed to be transitive. A set of dice is non-transitive if:

P(Die A > Die B) > 1/2
P(Die B > Die C) > 1/2
P(Die C > Die A) > 1/2

This creates an immutable cyclic advantage loop akin to Rock-Paper-Scissors, but where every interaction is governed by an exact mathematical probability distribution.

3. Cryptographic Stance Concealment (Zero-Knowledge Commit-Reveal)

To prevent peer snooping and counter-picking in real-time P2P multiplayer, TRIARCH integrates native WebCrypto SHA-256:

1. Commit: Salt = 32-byte secure hex; Hash = SHA-256(Die || Salt)
2. Broadcast: { type: 'DRAFT_COMMIT', commitment: '0x...' }
3. Reveal: { type: 'DRAFT_REVEAL', die: 'ruby-a', salt: '...' }
4. Verification: All peer nodes independently verify the SHA-256 digest before resolving clash.
